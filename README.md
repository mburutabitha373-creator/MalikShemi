# Malik & Shemi ❤️

Our little corner of the internet: a colourful, romantic memory space for Malik and Shemi.

## Live Website

**[Visit Malik & Shemi](https://malik-shemi.vercel.app/)**

## About

This website celebrates our story, our photos, and the small moments that make us smile. We first met on Snapchat and met in person on **April 26, 2025**, when we held hands for the first time.

## Features

- Romantic, responsive design for phones and laptops
- Personal photo gallery with captions
- First-meeting memory card
- Saved “little moments” counter using browser storage
- Personal love-note form with saved notes
- Surprise messages and floating heart animations
- Bright pink, red, purple, white, and pastel styling

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, usually `http://localhost:5173/`.

## Build

```bash
npm run build
```

## Deployment

The project is deployed with Vercel at [malik-shemi.vercel.app](https://malik-shemi.vercel.app/).

## Built With

- Vite
- Vanilla JavaScript
- CSS
- Local browser storage for notes and moments
